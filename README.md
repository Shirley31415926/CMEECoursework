### 2. Silwood Tree Survey
This assignment validates and cleans the synthetic tree survey data provided in data/silwood_trees_raw.csv.
The workflow standardises recognised values, validates record fields, and records all applicable rejection reasons for invalid records.  
Further information about the dataset is given in data/silwood_trees_metadata.md.

#### Algorithm Plan
1. Read the raw CSV and check its column names and order.
2. Process records after removing surrounding whitespace, validating each field.
3. Validate the record ID, location, genus, species, distance, and angle.
4. Standardise recognised location, genus, and species names.
5. Reject records with validation errors and record their source row numbers and rejection reasons.
6. Accept valid records and reserve their record IDs to detect later duplicates.
7. Sort accepted records by record ID and count accepted oak records by species.
8. Write the three output CSV files to disk. 

#### Pseudocode
```text
Read the raw CSV
Check the column names

For each record:
    Validate the ID, location, genus, species, distance and angle
    Check the genus/species combination
    If any validation errors exist:
        Save the record's source row and rejection reasons
    Otherwise:
        Save the cleaned record
        Reserve its ID

Sort accepted records by ID
Count accepted Quercus (oak) records by species
Write the three result files
```

#### Running the cleaner
Run the cleaner from the project root directory:
```bash
python3 code/clean_silwood_trees.py
```
The script generates three CSV files:
```bash
results/silwood_trees_clean.csv 
# Contains accepted and cleaned records, sorted by record ID.
```
```bash
results/silwood_tree_issues.csv 
# Contains rejected records, their source row numbers, and rejection reasons.
```
```bash
results/oak_species_counts.csv
# Contains counts of accepted oak records by species.
```

#### Testing
Run the automated tests from the project root:
```bash
python3 code/test_silwood_trees.py
```
The tests check record validation, text standardisation, missing and unrecognised values, invalid and out-of-range measurements, duplicate record IDs, multiple validation errors, accepted and rejected record processing, exact oak species matching, and cases with no accepted oak records.
They also check that importing the cleaner does not execute the main workflow and that repeated runs produce identical output files.


### 3. Calculate Tree Heights and Analyse Pound Hill Species Richness

This assignment contains two parts:
1. Calculating tree heights
2. Analysing plant species richness at Pound Hill

#### Part A: Tree Height Calculation
The calculation is based on:
$$
height_m = Distance.m \times \tan\left(\frac{Angle.degrees \times \pi}{180}\right)
$$
**1. Fixed-input script**
Run from the project root: 
```bash
Rscript code/TreeHeight.R
```
Input: ```bash data/trees.csv```
Output: ```bash results/TreeHts.csv ```

**2. Generalised-input script**
The generalised script accepts exactly one CSV file path as a command-line argument.
Run from the project root:
```bash
Rscript code/get_TreeHeight.R data/trees.csv
```
Input: ```bash data/trees.csv```
Output: ```bash results/trees_treeheights.csv```
The output filename is based on the input filename, with _treeheights.csv appended to its basename.
Example of invalid inputs:
```bash
# Invalid input: file does not exist
Rscript code/get_TreeHeight.R data/nonexistent.csv
# Invalid input: missing argument
Rscript code/get_TreeHeight.R
```

**3. Shell launcher**
The generalised R script can also be executed through the shell launcher:
```bash
bash code/run_get_TreeHeight.sh data/trees.csv
```
The launcher passes the supplied command-line arguments to get_TreeHeight.R.

**4. Testing**
The tree height scripts were tested using the original dataset, independent calculations, and invalid input cases. The Pound Hill analysis was checked for successful output generation and figure production.

#### Part B: Pound Hill Species Richness
The Pound Hill analysis uses the vegetation data and associated metadata to investigate plant species richness.

Run the analysis from the project root:
```bash
Rscript code/pound_hill_analysis.R
```
The analysis script uses the following input files:
```bash 
data/pound_hill_data.csv
data/pound_hill_meta_data.csv
```
The expected output files are stored in results/:
```bash
results/pound_hill_long.csv
results/pound_hill_plot_richness.csv
results/pound_hill_plot_richness.pdf
```
The CSV files contain the processed data and species richness results. The PDF contains the corresponding species richness figure
